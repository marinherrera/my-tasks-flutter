# 📝 Stressed Out Tasks
Aplicativo de gerenciamento de tarefas desenvolvido em Flutter e Dart como parte de atividade acadêmica de Engenharia de Software.
### Funcionalidades Atuais
O app permite criar e organizar tarefas por seções personalizadas, filtrar a visualização por status de conclusão e reordenar a lista de forma simples, contando com feedback visual e animações de interface.
### Melhorias Futuras
A ideia é continuar aprimorando o projeto no futuro — adicionando persistência de dados local e melhorias na arquitetura — com o intuito de evoluir o protótipo e eventualmente publicar o aplicativo para uso real.
